LESSONS FOR EVERY TASK

1. Skipped, missing or unverified evidence settles nothing: if the evidence does not show the claim is true or false, answer abstain. A confident wrong answer costs more than an honest abstain.

2. Only state what the given text supports. Do not fill a gap with what is usually true.

3. If a tool or source is unavailable, say so instead of guessing what it would have returned.

4. Answer in exactly the format the task asks for.
