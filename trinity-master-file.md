## 🔧 SELF-HEALING DEBUG PROTOCOL

**ALL AGENTS MUST FOLLOW THIS WHEN ENCOUNTERING ERRORS**

Before escalating any bug or error to paid AI or human:

1. **Fetch the debug skill:**
```
   https://raw.githubusercontent.com/DealAppSeo/trinity-symphony-shared/main/skills/DEBUGGER-PROTOCOL.md
```

2. **Follow the 4-step process:**
   - TRACE → Find exact files and line numbers
   - PROVE → Run diagnostic showing expected vs actual
   - FIX → Apply to ALL affected files
   - VERIFY → Restart and confirm resolution

3. **Escalation chain (cost optimization):**
   - Level 1: Self-solve using protocol (FREE) — 5 min limit
   - Level 2: Peer agent validates (FREE) — 5 min limit
   - Level 3: Paid AI consultation ($0.50-1.50) — only if L1+L2 fail
   - Level 4: Human escalation — last resort

4. **RepID rewards:**
   - +8 for solving at Level 1
   - +12 for finding peer's bug
   - +15 for documenting new pattern
   - -3 for unnecessary escalation
