## 🧮 **RIEMANN HYPOTHESIS BASICS**

### **The Problem**:
All non-trivial zeros of the Riemann zeta function ζ(s) have real part equal to 1/2.

### **Zeta Function**:
```
ζ(s) = Σ(1/n^s) for n=1 to ∞, where Re(s) > 1
```

### **Critical Strip**:
The region where 0 < Re(s) < 1, where non-trivial zeros are believed to lie on the line Re(s) = 1/2.
